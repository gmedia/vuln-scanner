# Aset dan workspace: nama target + satu tim

Dua hal yang sering tertukar:

- **Aset** = barang yang dicek: “website booking”, “VPS produksi”, “IP colo rak A”.
- **Workspace** = **perusahaan / hotel** tempat orang diundang. Satu org ≈ satu perusahaan di v1 (bukan banyak proyek bersarang).

## Aset (named targets)

Tanpa aset, orang mengetik IP/domain berulang dan salah sasaran. Dengan aset, Anda **label sekali**, pasang **satu jadwal**, dan paket membatasi jumlah:

- Basic: **1** aset
- Pro: hingga **3**
- Multi-asset: hingga **10**

Itu **batas keras** sesuai yang dijual. Jangan janji 50 domain di paket Basic.

Pakai nama manusia: “Situs utama”, bukan string acak. Jangan tempel data pelanggan orang lain ke contoh publik.

## Workspace (undangan & peran)

Workspace memakai peran kira-kira: **owner / admin / member / viewer**.

- Owner/admin: undang orang, kelola anggota
- Member: kerja scan sehari-hari
- Viewer: lihat jejak, tidak mengubah (berguna untuk GM / compliance)

**Kredit tetap pribadi** di v1. Undang rekan tidak otomatis menggabungkan pulsa jadi kas perusahaan. Dompet org = belakangan.

## Kapan Anda butuh ini

Satu orang + satu VPS: Basic + satu aset cukup. Beberapa properti / banyak SID: workspace + aset + paket Multi. Hospitality: cerita yang sama — satu hotel = satu workspace, banyak properti = banyak aset, bukan “satu login campur semua grup” tanpa batas.
